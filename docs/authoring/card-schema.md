# Card Authoring Schema

The Game Design Document is the canonical source for shared rules and card design. The files in `sets/` are authoritative for individual card text.

## Quest

Each Quest includes:

- Canonical ID
- Title
- Category
- Estimated effort
- Objective
- Measurable completion requirements
- Optional flavor text
- Access or substitution notes when necessary

## Condition

Each Condition includes:

- Canonical ID
- Title
- Category
- Mechanical type: restrictive, prescriptive or beneficial
- Scope: Full Round or Quest Activities
- Explicit rule
- Exceptions and compatibility notes when necessary
- Optional flavor text

## Curse

Each Curse includes:

- Canonical ID
- Title
- Category
- Effect
- Duration type: Persistent, Conditional or Quest-bound
- Scope: Full Round or Quest Activities
- Optional redemption for Conditional curses
- Exceptions and compatibility notes when necessary
- Optional flavor text

New cards must use the formatting and section conventions of the deck source in their set. Do not shorten card text for print in a way that changes its effect.
