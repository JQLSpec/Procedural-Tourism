# CORE Set

**Title:** Procedural Tourism: A Cooperative Travel Game
**Namespace:** `CORE`
**Product model:** Core game
**Status:** First playable prototype; combination testing and field playtesting pending

The CORE set contains the general-purpose playable decks. Its cards use the canonical `CORE` namespace and can be mixed with compatible expansion cards according to the Game Design Document.
