# Card Set Registry

This file is the central registry for card-set namespaces. Register a namespace here before assigning card identifiers in a new set.

| Namespace | Product title | Model | Destination or theme | Status |
|---|---|---|---|---|
| `CORE` | Procedural Tourism: A Cooperative Travel Game | Core game | General-purpose travel | Allocated; first playable prototype |

## Registration requirements

For each new namespace, record:

- Namespace and product title
- Product model: core expansion, destination pack, destination edition or thematic module
- Destination or theme, if applicable
- Included decks and intended mixing rules
- Owner and release status
- Localization sources and dates checked, when relevant
- Any intentional category-ratio or rules variation

Namespaces must be uppercase alphanumeric identifiers beginning with a letter. Card identifiers use the registered namespace in the form `<SET>-<DECK>-<CATEGORY>-<NUMBER>`.

`JPN`, `ITA`, `JPN02` and `RAIL01` remain illustrative, unallocated namespaces until they are registered for actual content.
